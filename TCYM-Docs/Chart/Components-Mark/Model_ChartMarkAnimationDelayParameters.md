# ChartMarkAnimationDelayParameters

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

提供 ECharts 动画延迟回调使用的批次总数与当前批次序号。

## 构造函数

### `ChartMarkAnimationDelayParameters(Int32,Int32)`

提供 ECharts 动画延迟回调使用的批次总数与当前批次序号。

| 参数 | 说明 |
| --- | --- |
| `Count` | 当前批次参与 Mark 动画的元素总数。 |
| `Index` | 当前元素在动画批次中的零基序号。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Count` | 当前批次参与 Mark 动画的元素总数。 |
| `Index` | 当前元素在动画批次中的零基序号。 |
