# ChartMarkCoordinate

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示当前 TCYM 二维坐标系统使用的严格二分量 mark 坐标；Cartesian 按 X/Y，Polar 按 Radius/Angle
解释两个分量。

## 构造函数

### `ChartMarkCoordinate(TCYM.UI.Chart.Model.ChartMarkCoordinateValue,TCYM.UI.Chart.Model.ChartMarkCoordinateValue)`

表示当前 TCYM 二维坐标系统使用的严格二分量 mark 坐标；Cartesian 按 X/Y，Polar 按 Radius/Angle
解释两个分量。

| 参数 | 说明 |
| --- | --- |
| `First` | 第一坐标维。 |
| `Second` | 第二坐标维。 |
