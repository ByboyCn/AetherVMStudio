# ChartMarkShape

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Components.Mark`　**Chart 版本**：`0.1.1.25`

## 概述

标识一个规范化 Mark 数据项的几何形态；该值不表示像素布局已经完成。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Area` | 由两个对角端点组成的 markArea。 |
| `AxisLine` | 沿另一坐标维完整伸展的一维 markLine。 |
| `LineSegment` | 由两个独立端点组成的 markLine。 |
| `Point` | 单个 markPoint 数据位置。 |
