# ChartMarkAreaArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Components.Mark`　**Chart 版本**：`0.1.1.25`

## 概述

集中定义每宿主系列 markArea Cartesian 布局制品键。

## 字段

| 名称 | 说明 |
| --- | --- |
| `LayoutArtifactName` | 每系列 markArea Cartesian 布局的稳定制品名称。 |

## 方法

### `LayoutFor(TCYM.UI.Chart.Model.ChartSeriesOption)`

按规范系列身份创建 markArea Layout 制品键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效宿主系列。 |

**返回：** 不会因系列重排而改变的作用域化制品键。
