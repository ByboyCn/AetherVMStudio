# ChartMarkLineBlurOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 markLine blur 的 label、itemStyle 与 lineStyle。

## 属性

| 名称 | 说明 |
| --- | --- |
| `LineStyle` | 获取或设置弱化态线样式；赋空显式重置整块样式。 |

## 方法

### `Clone`

创建公共状态、线样式和 presence 日志均隔离的副本。

**返回：** 内容等价的新弱化态。
