# ChartMarkBlurOption

> **类型**：class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 Mark blur 的公共状态字段，并补充 ECharts Marker state 的局部 z2。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Z2` | 获取或设置 blur 状态的局部图元层级。 |

## 方法

### `Clone`

创建公共 blur 状态和 z2 presence 均隔离的副本。

**返回：** 内容等价的新 Mark blur 状态。
