# ChartTextOverflow

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Text`　**Chart 版本**：`0.1.1.25`

## 概述

指定文本在宽高约束内的换行或截断策略。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Break` | 优先在空白边界换行，过长单词再按文本元素拆分。 |
| `BreakAll` | 允许在任意 Unicode 文本元素边界换行。 |
| `None` | 不换行也不截断，文字可以超出显式内容框。 |
| `Truncate` | 保持单行并按可用宽度使用省略文本截断。 |
