# ChartTextRun

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Text`　**Chart 版本**：`0.1.1.25`

## 概述

表示一个不可变的普通或富文本分段。

## 构造函数

### `ChartTextRun(String,String)`

初始化文本分段，并把空样式名规范化为普通文本。

| 参数 | 说明 |
| --- | --- |
| `text` | 分段文本；空引用规范化为空字符串。 |
| `styleName` | rich 样式名；空字符串规范化为空引用。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `StyleName` | 获取 rich 样式名；为空表示继承普通文本样式。 |
| `Text` | 获取当前分段的原始文本，可包含换行。 |
