# ChartTextLineLayout

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Text`　**Chart 版本**：`0.1.1.25`

## 概述

表示一行格式化文本的不可变 run 集合与几何。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Baseline` | 获取该行主基线。 |
| `Index` | 获取从零开始的行索引。 |
| `InkBounds` | 获取该行可能产生像素的包围盒。 |
| `LogicalBounds` | 获取该行逻辑框。 |
| `Runs` | 获取按视觉顺序排列的 run。 |
