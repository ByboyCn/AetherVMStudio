# ChartCoordinateValue

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.CoordinateSystems`　**Chart 版本**：`0.1.1.25`

## 概述

表示由 X、Y 两个 `ChartValue` 组成的通用数据坐标。

## 构造函数

### `ChartCoordinateValue(TCYM.UI.Chart.Data.ChartValue,TCYM.UI.Chart.Data.ChartValue)`

表示由 X、Y 两个 `ChartValue` 组成的通用数据坐标。

| 参数 | 说明 |
| --- | --- |
| `X` | 第一坐标维度。 |
| `Y` | 第二坐标维度。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `X` | 第一坐标维度。 |
| `Y` | 第二坐标维度。 |
