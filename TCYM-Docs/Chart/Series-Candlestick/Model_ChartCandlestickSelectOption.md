# ChartCandlestickSelectOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示公共 disabled、视觉字段和精确 Candlestick itemStyle 的 select 状态。

## 构造函数

### `ChartCandlestickSelectOption`

创建拥有独立 Candlestick itemStyle 的空 select 状态。

## 属性

| 名称 | 说明 |
| --- | --- |
| `ItemStyle` | 获取或设置精确的 Candlestick select itemStyle。 |

## 方法

### `Clone`

创建公共 select 与专用 itemStyle 均隔离的副本。

**返回：** 内容等价的新 Candlestick select 状态。
