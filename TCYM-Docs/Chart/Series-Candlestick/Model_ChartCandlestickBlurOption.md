# ChartCandlestickBlurOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示只含公共视觉字段和精确 Candlestick itemStyle 的 blur 状态。

## 构造函数

### `ChartCandlestickBlurOption`

创建拥有独立 Candlestick itemStyle 的空 blur 状态。

## 属性

| 名称 | 说明 |
| --- | --- |
| `ItemStyle` | 获取或设置精确的 Candlestick blur itemStyle。 |

## 方法

### `Clone`

创建公共 blur 与专用 itemStyle 均隔离的副本。

**返回：** 内容等价的新 Candlestick blur 状态。
