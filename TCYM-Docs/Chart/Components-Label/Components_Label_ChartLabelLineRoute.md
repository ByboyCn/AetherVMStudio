# ChartLabelLineRoute

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Components.Label`　**Chart 版本**：`0.1.1.25`

## 概述

保存公共三点标签引导线的不可变图表坐标。

## 构造函数

### `ChartLabelLineRoute(SkiaSharp.SKPoint,SkiaSharp.SKPoint,SkiaSharp.SKPoint)`

保存公共三点标签引导线的不可变图表坐标。

| 参数 | 说明 |
| --- | --- |
| `Start` | 位于 anchor 边界的第一点。 |
| `Bend` | 两段引导线的公共折点。 |
| `End` | 位于最终标签边界的第三点。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Bend` | 两段引导线的公共折点。 |
| `End` | 位于最终标签边界的第三点。 |
| `Start` | 位于 anchor 边界的第一点。 |
