# ChartLabelLineOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.Label`　**Chart 版本**：`0.1.1.25`

## 概述

配置中央 pass 在标签最终位置确定后生成的引导线。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Color` | 获取或设置引导线画刷；空值由中央 pass 使用标签文本颜色。 |
| `Length` | 获取或设置从 anchor 边界到折点的有限非负期望长度；固定端点不满足三角形条件时，<br />公共 router 会与 `Length2` 一起按比例退化。 |
| `Length2` | 获取或设置从折点到标签边界的有限非负期望长度；具体 series 可以据此决定外部标签位置，<br />以保证公共 router 精确实现两段长度。 |
| `Opacity` | 获取或设置有限透明度；快照时限制到零至一。 |
| `Show` | 获取或设置是否生成标签引导线。 |
| `Smooth` | 获取或设置是否按 ECharts 布尔 smooth 的固定 0.3 比例圆滑三点路线的真实折角。 |
| `Width` | 获取或设置有限非负线宽。 |

## 方法

### `Clone`

创建画刷和值均隔离的引导线配置快照。

**返回：** 颜色已按画刷快照契约隔离的新配置。
