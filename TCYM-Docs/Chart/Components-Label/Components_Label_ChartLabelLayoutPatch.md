# ChartLabelLayoutPatch

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Components.Label`　**Chart 版本**：`0.1.1.25`

## 概述

labelLayout callback 可以返回的受控差异；没有任何字段会暴露内部场景元素或可变布局集合。

## 构造函数

### `ChartLabelLayoutPatch(Nullable{Single},Nullable{Single},Nullable{Single},Nullable{Single},Nullable{Single},Nullable{TCYM.UI.Chart.Rendering.ChartTextAlign},Nullable{TCYM.UI.Chart.Rendering.ChartTextVerticalAlign},Nullable{TCYM.UI.Chart.Components.Label.ChartLabelMoveOverlap},Nullable{Boolean})`

labelLayout callback 可以返回的受控差异；没有任何字段会暴露内部场景元素或可变布局集合。

| 参数 | 说明 |
| --- | --- |
| `X` | 可选绝对图表 X 坐标。 |
| `Y` | 可选绝对图表 Y 坐标。 |
| `Dx` | 应用在绝对坐标之后的可选水平增量。 |
| `Dy` | 应用在绝对坐标之后的可选垂直增量。 |
| `Rotate` | 可选顺时针旋转角度。 |
| `Align` | 可选水平对齐覆盖。 |
| `VerticalAlign` | 可选垂直对齐覆盖。 |
| `MoveOverlap` | 可选重叠平移策略覆盖。 |
| `HideOverlap` | 可选隐藏重叠策略覆盖。 |
