# ChartLabelPlacement

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Components.Label`　**Chart 版本**：`0.1.1.25`

## 概述

表示锚点解析出的标签原点和自动对齐方式。

## 构造函数

### `ChartLabelPlacement(SkiaSharp.SKPoint,TCYM.UI.Chart.Rendering.ChartTextAlign,TCYM.UI.Chart.Rendering.ChartTextVerticalAlign)`

表示锚点解析出的标签原点和自动对齐方式。

| 参数 | 说明 |
| --- | --- |
| `Point` | 标签局部原点在图表坐标中的位置。 |
| `Align` | 未显式配置时使用的水平对齐。 |
| `VerticalAlign` | 未显式配置时使用的垂直对齐。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Align` | 未显式配置时使用的水平对齐。 |
| `Point` | 标签局部原点在图表坐标中的位置。 |
| `VerticalAlign` | 未显式配置时使用的垂直对齐。 |
