# ChartLabelPosition

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Components.Label`　**Chart 版本**：`0.1.1.25`

## 概述

定义公共标签相对于几何锚点的位置语义。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Auto` | 由锚点类型选择稳定默认位置。 |
| `Bottom` | 位于几何下方。 |
| `End` | 位于有方向几何的终点。 |
| `Inside` | 位于几何内部中心。 |
| `InsideBottom` | 位于几何内部下侧。 |
| `InsideBottomLeft` | 位于几何内部左下角。 |
| `InsideBottomRight` | 位于几何内部右下角。 |
| `InsideEnd` | 位于有方向几何内部、靠近结束端。 |
| `InsideLeft` | 位于几何内部左侧。 |
| `InsideRight` | 位于几何内部右侧。 |
| `InsideStart` | 位于有方向几何内部、靠近起始端。 |
| `InsideTop` | 位于几何内部上侧。 |
| `InsideTopLeft` | 位于几何内部左上角。 |
| `InsideTopRight` | 位于几何内部右上角。 |
| `Left` | 位于几何左侧。 |
| `Middle` | 位于有方向几何的中点。 |
| `Outside` | 位于有方向几何的值端外侧；具体系列锚点负责根据数值方向与坐标轴反转状态解析实际方位。 |
| `Right` | 位于几何右侧。 |
| `Start` | 位于有方向几何的起点。 |
| `Top` | 位于几何上方。 |
