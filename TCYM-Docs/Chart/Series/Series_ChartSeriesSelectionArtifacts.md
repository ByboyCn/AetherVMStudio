# ChartSeriesSelectionArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series`　**Chart 版本**：`0.1.1.25`

## 概述

定义每系列选择掩码的稳定制品键。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ArtifactName` | 获取选择掩码制品的稳定名称。 |

## 方法

### `ForSeries(TCYM.UI.Chart.Model.ChartSeriesOption)`

为指定系列创建稳定规范身份作用域的选择掩码键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效系列节点。 |

**返回：** 系列作用域的强类型制品键。
