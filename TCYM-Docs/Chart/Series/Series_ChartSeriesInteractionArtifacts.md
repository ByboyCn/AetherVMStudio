# ChartSeriesInteractionArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series`　**Chart 版本**：`0.1.1.25`

## 概述

定义每系列 emphasis 掩码的稳定制品键。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ArtifactName` | 获取制品稳定名称。 |
| `IndexMapArtifactName` | 获取 presentation inside 索引映射制品的稳定名称。 |

## 方法

### `ForSeries(TCYM.UI.Chart.Model.ChartSeriesOption)`

为指定系列创建稳定规范身份作用域的掩码键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效系列节点。 |

**返回：** 系列作用域的强类型制品键。

### `IndexMapForSeries(TCYM.UI.Chart.Model.ChartSeriesOption)`

为指定系列创建 presentation inside 索引映射的强类型制品键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效系列节点。 |

**返回：** 系列作用域的强类型制品键。
