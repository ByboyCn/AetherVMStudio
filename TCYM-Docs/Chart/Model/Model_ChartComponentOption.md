# ChartComponentOption

> **类型**：abstract class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

具有通用矩形布局字段的组件选项基类。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Bottom` | 获取或设置组件底部位置。 |
| `ComponentType` | 获取组件注册与合并所使用的类型名。 |
| `Height` | 获取或设置组件高度。 |
| `Left` | 获取或设置组件左侧位置。 |
| `MainType` | 获取节点参与顶层合并与注册表匹配的主类型。 |
| `Right` | 获取或设置组件右侧位置。 |
| `Top` | 获取或设置组件顶部位置。 |
| `Width` | 获取或设置组件宽度。 |
