# IChartMarkHostSeriesOption

> **类型**：interface　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

标识能承载公共 markPoint、markLine 和 markArea 的系列 option。三个块只描述数据和表现；
统计、布局、View 与交互均由公共 Mark 模块拥有。

## 属性

| 名称 | 说明 |
| --- | --- |
| `MarkArea` | 获取该系列的 markArea 配置。 |
| `MarkLine` | 获取该系列的 markLine 配置。 |
| `MarkPoint` | 获取该系列的 markPoint 配置。 |
