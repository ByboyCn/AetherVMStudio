# ChartTheme

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示图表主题。主题是构建 effective 选项时的默认值来源，不应反向修改 canonical 选项。
默认调色板以 ECharts 6 明亮主题为设计基线，可由 `Color` 覆盖。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Background` | 获取或设置图表背景画刷；为空时由宿主背景决定。 |
| `Palette` | 获取按系列顺序循环使用的主题调色板。 |
| `TextColor` | 获取或设置组件默认文本画刷。 |
| `Typeface` | 获取或设置默认字体；为空时使用渲染后端默认字体。字体按借用资源处理，主题及其副本均不会释放它；<br />调用方必须保证字体在所有使用该主题的图表存活期间保持有效。 |

## 方法

### `Clone`

创建主题快照。画刷通过其快照契约隔离，避免调用方后续修改污染已发布主题。

**返回：** 与当前主题内容等价、可独立修改的副本；借用的 `SKTypeface` 引用除外。
