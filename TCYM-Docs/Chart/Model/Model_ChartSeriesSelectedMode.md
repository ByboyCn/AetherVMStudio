# ChartSeriesSelectedMode

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

定义系列数据项的运行时选择模式。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Disabled` | 禁用程序 action 与点击选择；这是未指定 `selectedMode` 时的有效默认值。 |
| `Multiple` | 同一系列允许多个源数据项同时处于选中状态。 |
| `Series` | 把系列全部可选择数据项作为一个整体切换选择状态。 |
| `Single` | 同一系列只允许一个源数据项处于选中状态。 |
