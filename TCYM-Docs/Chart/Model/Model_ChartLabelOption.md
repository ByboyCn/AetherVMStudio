# ChartLabelOption

> **类型**：class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

系列及状态共用的标签配置。所有字段采用 presence-aware 合并；`Rich` 还记录
单个样式的新增、删除与深度补丁。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Align` | 获取或设置水平对齐方式。 |
| `Color` | 获取或设置文本画刷；为空可恢复继承颜色。 |
| `Distance` | 获取或设置标签与图元的距离。 |
| `FontSize` | 获取或设置字体大小。 |
| `Formatter` | 获取或设置 ECharts 风格的格式模板。 |
| `FormatterCallback` | 获取或设置代码格式化回调。回调运行在受保护的扩展边界内，不应保存上下文用于异步修改。 |
| `Offset` | 获取或设置标签二维像素偏移。 |
| `Position` | 获取或设置标签位置关键字，例如 `top`、`inside`。 |
| `Rich` | 获取或设置富文本样式字典。属性赋值表示整体替换，会先深复制当前内容，再记录 clear<br />与逐项 set；赋入空字典或空值表示整体清空。增量更新请使用 getter 返回字典的索引器、<br />`Remove` 或<br />`Clear`，其 presence 日志会在克隆与合并中保留。 |
| `Rotate` | 获取或设置顺时针旋转角度（度）。 |
| `Show` | 获取或设置是否显示标签。 |
| `Typeface` | 获取或设置字体。字体按借用资源处理，标签选项、选项快照和图表均不会释放它；调用方必须保证<br />字体在引用它的图表及所有克隆选项使用期间保持有效。 |
| `ValueAnimation` | 获取或设置数据更新时标签文本是否进行数值插值动画；具体系列决定有效默认值和执行阶段。 |
| `VerticalAlign` | 获取或设置垂直对齐方式。 |

## 方法

### `Clone`

创建值、富文本字典与 presence 日志均独立的副本；字体仍遵循借用资源契约。

**返回：** 内容等价的新标签选项；其中 `SKTypeface` 引用会共享。

### `Reset`

在下一次合并时显式清除整个嵌套标签块。公开入口不可重写，避免外部派生类型改变
option backing 的重置语义。
