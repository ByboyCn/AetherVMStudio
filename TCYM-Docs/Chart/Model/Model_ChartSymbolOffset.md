# ChartSymbolOffset

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 symbol 在水平方向和垂直方向上的有限像素或百分比偏移。

## 构造函数

### `ChartSymbolOffset(TCYM.UI.Chart.Model.ChartLength,TCYM.UI.Chart.Model.ChartLength)`

创建二维 symbol 偏移，并拒绝不属于 ECharts symbolOffset 的布局关键字。

| 参数 | 说明 |
| --- | --- |
| `horizontal` | 水平像素或百分比偏移。 |
| `vertical` | 垂直像素或百分比偏移。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Horizontal` | 获取水平像素或百分比偏移。 |
| `Vertical` | 获取垂直像素或百分比偏移。 |
