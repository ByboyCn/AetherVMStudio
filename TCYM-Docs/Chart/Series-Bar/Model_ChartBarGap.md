# ChartBarGap

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 ECharts `barGap` 的数值或百分比联合值。数值是相对柱宽的直接比例而不是像素，
百分数会在布局时除以 100；`-100%` 或比例 `-1` 表示柱槽完全重叠。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Kind` | 获取调用方使用的数值表达形式。 |
| `Ratio` | 获取供柱槽布局直接使用的比例。 |
| `Value` | 获取直接比例或百分数形式的原始有限值。 |

## 方法

### `FromPercent(Single)`

从百分数字面量创建间距。

| 参数 | 说明 |
| --- | --- |
| `percent` | 有限百分数。 |

**返回：** 百分比语法的间距联合值。

### `FromRatio(Single)`

从相对柱宽的直接比例创建间距。

| 参数 | 说明 |
| --- | --- |
| `ratio` | 有限的直接比例。 |

**返回：** 数值语法的间距联合值。

### `Percent(Single)`

从百分数字面量创建间距的简写入口。

| 参数 | 说明 |
| --- | --- |
| `percent` | 有限百分数。 |

**返回：** 百分比语法的间距联合值。

### `ToString`

返回可稳定记录在诊断和测试中的不变区域文本。

**返回：** 百分比值带百分号，直接比例不带单位。
