# ChartEventType

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Interaction`　**Chart 版本**：`0.1.1.25`

## 概述

图表指针交互事件类型。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Click` | 在同一命中目标上完成一次单击。 |
| `DoubleClick` | 主机报告双击。 |
| `GlobalOut` | 指针离开整个图表内容区。 |
| `MouseDown` | 主机按下指针或鼠标按钮。 |
| `MouseMove` | 指针在图表内容区移动。 |
| `MouseOut` | 指针离开先前命中的图形。 |
| `MouseOver` | 指针进入某个可命中图形。 |
| `MouseUp` | 主机释放指针或鼠标按钮。 |
| `MouseWheel` | 鼠标滚轮滚动。 |
| `PointerCancel` | 活动指针序列被宿主取消。 |
