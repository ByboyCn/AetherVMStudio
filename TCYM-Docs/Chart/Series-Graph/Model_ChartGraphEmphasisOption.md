# ChartGraphEmphasisOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

Graph Emphasis 状态的节点、边描边和边标签补丁。

## 属性

| 名称 | 说明 |
| --- | --- |
| `EdgeLabel` | 此状态的边标签样式。 |
| `Focus` | 聚焦范围：none、self 或 series；邻接聚焦使用系列 FocusNodeAdjacency。 |
| `LineStyle` | 此状态的边描边样式。 |

## 方法

### `Clone`

创建独立的状态及 presence 副本。
