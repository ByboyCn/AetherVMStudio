# ChartGraphModule

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series`　**Chart 版本**：`0.1.1.25`

## 概述

安装 Graph 模型验证、节点/边数据、布局及持久 View。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ModuleKey` | Graph 模块的稳定注册键。 |

## 方法

### `Register(TCYM.UI.Chart.Core.ChartRegistry)`

原子安装 Graph；调用前须安装 SeriesFoundation 模块。
