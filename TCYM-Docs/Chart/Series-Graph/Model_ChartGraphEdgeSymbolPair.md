# ChartGraphEdgeSymbolPair

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

分别配置 Graph 边起点和终点符号；默认结构为两端 None。

## 构造函数

### `ChartGraphEdgeSymbolPair(TCYM.UI.Chart.Model.ChartGraphEdgeSymbol,TCYM.UI.Chart.Model.ChartGraphEdgeSymbol)`

创建起终点符号对。

| 参数 | 说明 |
| --- | --- |
| `start` | 源节点一端的符号。 |
| `end` | 目标节点一端的符号。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `End` | 获取目标节点一端的符号。 |
| `Start` | 获取源节点一端的符号。 |
