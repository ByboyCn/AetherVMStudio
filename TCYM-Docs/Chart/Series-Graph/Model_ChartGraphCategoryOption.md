# ChartGraphCategoryOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

Graph 分类名称及节点共享样式。

## 属性

| 名称 | 说明 |
| --- | --- |
| `ItemStyle` | 分类节点的正常样式。 |
| `Label` | 分类节点的标签样式。 |
| `Name` | 唯一的非空分类名称，同时用于图例。 |
| `Symbol` | 分类节点符号。 |
| `SymbolSize` | 分类节点符号尺寸。 |

## 方法

### `Clone`

创建独立的分类副本。
