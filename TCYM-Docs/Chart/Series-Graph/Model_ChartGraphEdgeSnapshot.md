# ChartGraphEdgeSnapshot

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

不可变边快照；样式返回隔离副本。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Curveness` | 曲率。 |
| `Id` | 业务身份。 |
| `Name` | 显示名。 |
| `Source` | 源节点端点。 |
| `Symbol` | 获取不可变的起终点符号覆盖。 |
| `SymbolSize` | 获取不可变的起终点尺寸覆盖。 |
| `Target` | 目标节点端点。 |
| `Value` | 原始值。 |

## 方法

### `GetBlur`

获取隔离的 Blur 状态。

### `GetEmphasis`

获取隔离的 Emphasis 状态。

### `GetLabel`

获取隔离的标签样式。

### `GetLineStyle`

获取隔离的描边样式。

### `GetSelect`

获取隔离的 Select 状态。
