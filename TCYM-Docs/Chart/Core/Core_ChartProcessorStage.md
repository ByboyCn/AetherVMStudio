# ChartProcessorStage

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

定义图表构建管线中处理器的执行阶段。

## 说明

枚举数值同时决定阶段顺序；自定义处理器必须选择一个已定义值。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Data` | 解析、筛选或转换系列数据。 |
| `Layout` | 计算坐标系和图元几何布局。 |
| `Normalize` | 归一化有效配置并补齐默认值；只有此阶段可形成待发布的配置和主题。 |
| `PostRender` | 在持久视图之后绘制临时覆盖层。 |
| `Visual` | 计算颜色、样式及其他视觉编码。 |
