# ChartUpdateFlags

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

指定一次状态变化需要重新运行的图表阶段。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Data` | 重新处理数据及其后续阶段。 |
| `Layout` | 重新计算布局及其后续阶段。 |
| `None` | 无需更新。 |
| `Normalize` | 重新归一化配置并运行完整管线。 |
| `Rebuild` | 从归一化到渲染执行完整重建。 |
| `Render` | 重新协调或绘制持久视图。 |
| `Visual` | 重新计算视觉编码。 |
