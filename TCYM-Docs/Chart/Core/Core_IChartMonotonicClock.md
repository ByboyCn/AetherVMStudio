# IChartMonotonicClock

> **类型**：interface　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

提供不受系统墙钟校时影响的单调经过时间，供逐帧调度与可重复测试共同使用。

## 说明

实现必须保证 `Elapsed` 不回拨，并且返回有限的非负 `TimeSpan`。
该窄接口不依赖反射、动态代码或平台计时器句柄，可安全进入 NativeAOT 公共契约。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Elapsed` | 获取时钟自身起点以来的单调非负经过时间。 |
