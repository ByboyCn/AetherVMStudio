# ChartPointerEventType

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

定义交互控制器接收的原始指针事件类型。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Cancel` | 指针序列被宿主取消。 |
| `DoubleClick` | 双击。 |
| `Down` | 指针按下。 |
| `Leave` | 指针离开图表视口。 |
| `Move` | 指针移动。 |
| `Up` | 指针释放。 |
| `Wheel` | 滚轮滚动。 |
