# ChartRegistryChangeKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

定义注册表修改涉及的扩展类别。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Action` | action 处理器。 |
| `ComponentRenderer` | 旧式组件渲染器。 |
| `ComponentView` | 组件持久视图工厂。 |
| `CoordinateSystem` | 坐标系工厂。 |
| `InteractionController` | 交互控制器。 |
| `Module` | 通过单次原子事务提交、并携带全部注册项明细的模块。 |
| `Processor` | 处理器。 |
| `SeriesAttachmentView` | 按宿主系列动态存在的持久 attachment View 工厂。 |
| `SeriesRenderer` | 旧式系列渲染器。 |
| `SeriesView` | 系列持久视图工厂。 |
