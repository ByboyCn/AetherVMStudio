# ChartViewRemoval

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Core`　**Chart 版本**：`0.1.1.25`

## 概述

描述视图如何处理移除。返回 `Default` 使用引擎默认退出效果；视图通过构建上下文
安排自己的退出动画后，可返回 `Custom`。

## 构造函数

### `ChartViewRemoval(Boolean,Int32)`

描述视图如何处理移除。返回 `Default` 使用引擎默认退出效果；视图通过构建上下文
安排自己的退出动画后，可返回 `Custom`。

| 参数 | 说明 |
| --- | --- |
| `IsCustom` | 是否由视图负责退出动画。 |
| `Duration` | 退出过程的预计毫秒数。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Default` | 获取由引擎执行默认退出处理的策略。 |
| `Duration` | 退出过程的预计毫秒数。 |
| `IsCustom` | 是否由视图负责退出动画。 |

## 方法

### `Custom(Int32)`

创建由视图自行安排退出动画的策略。

| 参数 | 说明 |
| --- | --- |
| `duration` | 预计持续时间（毫秒）；负值按零处理。 |

**返回：** 自定义移除策略。
