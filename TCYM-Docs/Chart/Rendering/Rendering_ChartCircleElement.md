# ChartCircleElement

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

绘制圆形的场景元素。

## 属性

| 名称 | 说明 |
| --- | --- |
| `CenterX` | 获取或设置圆心的局部 X 坐标。 |
| `CenterY` | 获取或设置圆心的局部 Y 坐标。 |
| `HitTestTolerance` | 获取或设置描边命中的额外容差（像素）。 |
| `Radius` | 获取或设置圆半径；绘制时负值按 0 处理。 |
