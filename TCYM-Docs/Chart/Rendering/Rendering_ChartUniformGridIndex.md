# ChartUniformGridIndex

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

面向批量图元命中的轻量均匀网格索引。

## 构造函数

### `ChartUniformGridIndex`

创建一个空的均匀网格索引。

## 属性

| 名称 | 说明 |
| --- | --- |
| `CellSize` | 获取或设置网格单元边长（像素）。 |

## 方法

### `Build(Int32,Func{Int32,SkiaSharp.SKRect})`

按项的包围盒重新构建全部网格桶。

| 参数 | 说明 |
| --- | --- |
| `count` | 需要索引的项数；小于等于零时只清空已有内容。 |
| `getBounds` | 按从零开始的项索引返回局部坐标包围盒的回调。 |

**说明：** 包围盒覆盖的每个单元都会记录该项索引；含非有限坐标的包围盒会被忽略。
跨度超过安全上限的项会进入全局溢出候选表，查询仍可得到它而不会展开海量网格桶。

### `Clear`

移除全部网格桶和候选项索引。

### `Query(Single,Single)`

查询包含指定局部坐标的网格单元中记录的候选项索引。

| 参数 | 说明 |
| --- | --- |
| `x` | 局部坐标的 X 分量。 |
| `y` | 局部坐标的 Y 分量。 |

**返回：** 桶内索引的只读视图；坐标无效或单元为空时返回空列表。

**说明：** 结果仅是粗筛候选，调用者仍须执行精确几何命中测试。
