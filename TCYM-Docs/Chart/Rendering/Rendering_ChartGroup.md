# ChartGroup

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

可变换、可裁剪的轻量场景分组。组拥有其子元素的生命周期，并按 ZLevel、Z、Z2
与稳定插入顺序统一绘制和反向命中；场景树会拒绝重复节点和祖先环。

## 构造函数

### `ChartGroup`

创建空场景组。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Children` | 获取子元素的实时只读视图。 |
| `HitArea` | 获取或设置组自身的局部命中区域；为空时仅子元素可被命中。 |

## 方法

### `Add()`

把尚未释放且没有其他父级的元素加入组，并转移其场景所有权。

| 参数 | 说明 |
| --- | --- |
| `element` | 待加入的元素。 |

**返回：** 原元素，便于链式配置。

### `Clear`

脱离并释放全部子元素。所有子元素都会获得一次清理机会；多个失败会聚合后抛出，
但组自身仍会恢复为空且可继续使用。

### `Remove(TCYM.UI.Chart.Rendering.ChartElement,Boolean)`

从组中移除元素，并可选择立即释放其资源。

| 参数 | 说明 |
| --- | --- |
| `element` | 待移除的直接子元素。 |
| `dispose` | 是否在脱离后调用元素的 `Dispose`。 |

**返回：** 元素原本属于该组时为 `true`。
