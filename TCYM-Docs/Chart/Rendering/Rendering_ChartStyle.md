# ChartStyle

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

轻量场景元素的通用视觉样式。
属性会记录是否被显式赋值，因此 emphasis/blur/select 样式可以只声明差异项；
显式赋 `null` 也会覆盖并清除基础样式中的画刷。

## 属性

| 名称 | 说明 |
| --- | --- |
| `AntiAlias` | 获取或设置是否启用抗锯齿。 |
| `Fill` | 获取或设置填充画刷；设置值会按画刷快照契约隔离。 |
| `LineDash` | 获取或设置虚线长度序列。赋值时会复制为只读快照；`null` 表示实线。 |
| `LineDashOffset` | 获取或设置虚线图案沿路径方向的偏移量。 |
| `MiterLimit` | 获取或设置斜接连接的最大比例。 |
| `Opacity` | 获取或设置样式透明度；绘制时还会与元素及父组透明度相乘。 |
| `Shadow` | 获取或设置路径阴影；赋空会显式清除基础样式继承的阴影。 |
| `Stroke` | 获取或设置描边画刷；设置值会按画刷快照契约隔离。 |
| `StrokeCap` | 获取或设置开放路径端点的线帽样式。 |
| `StrokeJoin` | 获取或设置线段连接处的样式。 |
| `StrokeWidth` | 获取或设置描边宽度（像素）。 |

## 方法

### `Clone`

返回完整副本，并保留“哪些字段被显式赋值”的差异样式语义。

**返回：** 与当前样式相互隔离的副本。

### `MergeOnto(TCYM.UI.Chart.Rendering.ChartStyle)`

把当前样式中显式赋值的字段覆盖到基础样式之上。

| 参数 | 说明 |
| --- | --- |
| `basis` | 提供未显式字段的基础样式。 |

**返回：** 合并后的完整新样式，不修改任一输入。
