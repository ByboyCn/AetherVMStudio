# ChartScene

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

一张图表拥有的轻量场景树。场景按 ZLevel 建立根级图层，统一负责绘制、命中和
子元素资源释放；释放后不允许重新使用。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Root` | 获取场景根节点。兼容代码可以直接添加自有节点；系列渲染器宜使用<br />`AddToLayer`` 或 `GetLayer`，使跨组件的 ZLevel 在根层统一排序。 |
| `Viewport` | 获取图表内容区的裁剪边界；仅图表内核可更新。 |

## 方法

### `AddToLayer(,Nullable{Int32})`

把节点添加到全局 ZLevel 图层。层内仍按节点的 Z、Z2 和插入顺序稳定排序。

| 参数 | 说明 |
| --- | --- |
| `element` | 待加入且尚未拥有父级的元素。 |
| `zLevel` | 可选层级；为空时使用元素当前的 ZLevel。 |

**返回：** 原元素，便于链式配置。

### `Clear`

释放并移除全部场景元素，同时保留场景对象供重新构建。即使某个元素清理失败，
内部图层索引也会重置，避免返回已释放图层。

### `Dispose`

释放整棵场景树及全部图层。调用幂等，释放后其他操作会抛出异常。

### `GetLayer(Int32)`

获取或按需创建一个由根节点统一排序的 ZLevel 图层。

| 参数 | 说明 |
| --- | --- |
| `zLevel` | 图层的全局层级。 |

**返回：** 由场景拥有的持久图层组；调用方不得单独释放。

### `HitTest(Single,Single)`

在场景根坐标中执行反向绘制顺序的命中测试。

| 参数 | 说明 |
| --- | --- |
| `x` | 视口内 X 坐标。 |
| `y` | 视口内 Y 坐标。 |

**返回：** 最上层命中结果；视口外或未命中时为 `null`。

### `Render(SkiaSharp.SKCanvas)`

在视口裁剪内绘制完整场景树。

| 参数 | 说明 |
| --- | --- |
| `canvas` | 目标 Skia 画布。 |
