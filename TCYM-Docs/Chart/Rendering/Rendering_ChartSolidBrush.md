# ChartSolidBrush

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

使用单一颜色绘制的不可变画刷。

## 构造函数

### `ChartSolidBrush(SkiaSharp.SKColor)`

使用单一颜色绘制的不可变画刷。

| 参数 | 说明 |
| --- | --- |
| `color` | 基础颜色；元素透明度会与其 Alpha 相乘。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Color` | 获取基础颜色。 |
