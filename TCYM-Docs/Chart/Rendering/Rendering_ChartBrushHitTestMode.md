# ChartBrushHitTestMode

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Rendering`　**Chart 版本**：`0.1.1.25`

## 概述

定义画刷透明度是否影响场景元素命中。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Geometry` | 只要配置了填充或有效描边就按几何命中，不检查画刷 Alpha；这是默认行为，可用全透明画刷建立交互代理。 |
| `VisiblePaint` | 仅让声明可能产生非全透明像素的画刷参与命中；内置纯色和渐变可精确判断，自定义画刷默认按可能可见处理。 |
