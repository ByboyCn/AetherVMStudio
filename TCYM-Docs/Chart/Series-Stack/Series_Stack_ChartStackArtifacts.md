# ChartStackArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series.Stack`　**Chart 版本**：`0.1.1.25`

## 概述

集中定义公共堆叠处理器发布的稳定每系列制品键。

## 字段

| 名称 | 说明 |
| --- | --- |
| `SeriesSnapshotArtifactName` | 获取每系列公共堆叠快照的稳定制品名称。 |

## 方法

### `ForSeries(TCYM.UI.Chart.Model.ChartSeriesOption)`

按系列规范运行时身份创建公共堆叠快照键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效系列。 |

**返回：** 稳定每系列制品键。
