# ChartLineStyleTypeKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

指定折线描边线型联合值的当前类别。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Dashed` | 预定义虚线，对应 ECharts 的 `dashed`。 |
| `DashLength` | 使用一个非负有限数值作为重复虚线长度。 |
| `DashPattern` | 使用一组非空的非负有限数值作为自定义虚线图案。 |
| `Dotted` | 预定义点线，对应 ECharts 的 `dotted`。 |
| `Solid` | 连续实线，对应 ECharts 的 `solid`。 |
