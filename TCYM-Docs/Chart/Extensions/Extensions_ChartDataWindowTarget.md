# ChartDataWindowTarget

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Extensions`　**Chart 版本**：`0.1.1.25`

## 概述

使用强类型轴维度和同类索引标识一个 dataZoom 目标。

## 构造函数

### `ChartDataWindowTarget(TCYM.UI.Chart.Extensions.ChartDataWindowAxisKind,Int32)`

创建 dataZoom 目标。

| 参数 | 说明 |
| --- | --- |
| `axisKind` | 目标轴维度。 |
| `axisIndex` | 目标轴在相同维度中的非负索引。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `AxisIndex` | 获取目标轴在相同维度中的索引。 |
| `AxisKind` | 获取目标轴维度。 |
