# ChartVisualEncodingBoundarySnapshot

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Extensions`　**Chart 版本**：`0.1.1.25`

## 概述

描述空桥接处理器已经越过的 Visual 编码边界。

## 构造函数

### `ChartVisualEncodingBoundarySnapshot(TCYM.UI.Chart.Extensions.ChartVisualEncodingPhase)`

创建一个 Visual 编码边界标记。

| 参数 | 说明 |
| --- | --- |
| `phase` | 边界所在阶段。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Phase` | 获取边界所在阶段。 |
