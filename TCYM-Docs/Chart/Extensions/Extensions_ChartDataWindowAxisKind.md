# ChartDataWindowAxisKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Extensions`　**Chart 版本**：`0.1.1.25`

## 概述

标识 dataZoom 窗口约束的坐标轴维度。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Angle` | Polar 角度轴。 |
| `Radius` | Polar 半径轴。 |
| `Single` | 未来 singleAxis 坐标轴。 |
| `X` | Cartesian X 轴。 |
| `Y` | Cartesian Y 轴。 |
