# ChartVisualMapPieceLayoutSnapshot

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.VisualMap`　**Chart 版本**：`0.1.1.25`

## 概述

保存一个 piecewise 项的最终显示、选择和命中布局。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Fill` | 获取深快照填充。 |
| `HitBounds` | 获取整项命中边界。 |
| `Key` | 获取组件内稳定逻辑 key。 |
| `Label` | 获取最终显示文本。 |
| `Selected` | 获取当前 Engine-local 选择值。 |
| `SymbolBounds` | 获取 symbol 边界。 |
| `Text` | 获取可选预布局文本。 |
