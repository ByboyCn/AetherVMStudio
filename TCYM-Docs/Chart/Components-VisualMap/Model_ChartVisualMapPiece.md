# ChartVisualMapPiece

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

定义 piecewise VisualMap 的精确值或开闭区间以及逐通道视觉覆盖。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Gt` | 获取或设置严格大于的开区间下界。 |
| `Gte` | 获取或设置大于等于的闭区间下界。 |
| `Label` | 获取或设置替代自动区间文字的标签。 |
| `Lt` | 获取或设置严格小于的开区间上界。 |
| `Lte` | 获取或设置小于等于的闭区间上界。 |
| `Max` | 获取或设置兼容语义的闭区间上界。 |
| `Min` | 获取或设置兼容语义的闭区间下界。 |
| `Value` | 获取或设置优先于区间的精确强类型值。 |
| `Visual` | 获取或设置该 piece 自己声明的视觉通道。 |

## 方法

### `Clone`

创建值、视觉序列和 presence 状态均独立的副本。
