# ChartVisualMapSeriesTarget

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

把一个系列索引或 ID 绑定到该系列独立的 VisualMap 维度。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Dimension` | 获取或设置该目标独立使用的维度索引或名称。 |
| `SeriesId` | 获取或设置目标系列 ID。 |
| `SeriesIndex` | 获取或设置目标系列索引。 |

## 方法

### `Clone`

创建值和 presence 状态均独立的目标副本。
