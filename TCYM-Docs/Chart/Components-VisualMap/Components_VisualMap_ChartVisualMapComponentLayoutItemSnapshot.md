# ChartVisualMapComponentLayoutItemSnapshot

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.VisualMap`　**Chart 版本**：`0.1.1.25`

## 概述

保存一个 VisualMap 组件完整、托管且不可变的场景布局。

## 属性

| 名称 | 说明 |
| --- | --- |
| `BarBounds` | 获取渐变条或 piece 列表内容边界。 |
| `Bounds` | 获取完整组件边界。 |
| `Calculable` | 获取 continuous 是否可拖动。 |
| `CommittedRange` | 获取映射管线消费的已提交范围。 |
| `ComponentId` | 获取组件 ID。 |
| `ComponentIndex` | 获取同主类型索引。 |
| `ComponentName` | 获取组件名称。 |
| `DisplayRange` | 获取 View 显示的拖动预览或已提交范围。 |
| `GradientColors` | 获取 continuous 渐变颜色。 |
| `HoverLink` | 获取是否启用 hoverLink。 |
| `IndicatorBounds` | 获取指示器边界。 |
| `Inverse` | 获取是否反向显示。 |
| `Kind` | 获取布局种类。 |
| `Labels` | 获取 continuous 端点或其他组件级文本。 |
| `LowerHandleBounds` | 获取低端手柄边界。 |
| `Orient` | 获取布局方向。 |
| `Pieces` | 获取 piecewise 项。 |
| `Realtime` | 获取 continuous 是否实时提交。 |
| `RuntimeUid` | 获取 canonical RuntimeUid。 |
| `Show` | 获取是否显示。 |
| `Silent` | 获取是否静默。 |
| `UpperHandleBounds` | 获取高端手柄边界。 |
