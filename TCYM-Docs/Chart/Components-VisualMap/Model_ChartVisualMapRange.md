# ChartVisualMapRange

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 continuous VisualMap 的两个有限选择端点。

## 构造函数

### `ChartVisualMapRange(Double,Double)`

创建尚未按有效 extent 排序或裁剪的范围。

| 参数 | 说明 |
| --- | --- |
| `start` | 第一个有限端点。 |
| `end` | 第二个有限端点。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `End` | 获取调用方提供的第二个端点。 |
| `Start` | 获取调用方提供的第一个端点。 |
