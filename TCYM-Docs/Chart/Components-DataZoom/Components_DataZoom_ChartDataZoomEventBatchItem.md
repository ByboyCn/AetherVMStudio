# ChartDataZoomEventBatchItem

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.DataZoom`　**Chart 版本**：`0.1.1.25`

## 概述

保存一个 dataZoom 组件在 action 完成后的实际百分比窗口。

## 属性

| 名称 | 说明 |
| --- | --- |
| `DataZoomId` | 获取目标组件的可选显式 ID。 |
| `DataZoomIndex` | 获取目标组件的同主类型索引。 |
| `End` | 获取 action 最终提交的实际有效窗口终点。 |
| `Start` | 获取 action 最终提交的实际有效窗口起点。 |
