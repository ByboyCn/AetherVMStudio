# ChartDataZoomInteractionTrigger

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

指定 inside dataZoom 的某一种指针交互是否启用，以及需要按下的修饰键。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Alt` | 仅按下 Alt 键时启用该交互。 |
| `Ctrl` | 仅按下 Ctrl 键时启用该交互。 |
| `Disabled` | 禁用该交互。 |
| `Enabled` | 不要求修饰键，直接启用该交互。 |
| `Shift` | 仅按下 Shift 键时启用该交互。 |
