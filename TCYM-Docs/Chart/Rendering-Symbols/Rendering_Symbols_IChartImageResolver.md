# IChartImageResolver

> **类型**：interface　**命名空间**：`TCYM.UI.Chart.Rendering.Symbols`　**Chart 版本**：`0.1.1.25`

## 概述

把 `image://` 载荷解析为独占图片资源。接口不限定载荷是文件、网络、资源还是数据 URI，
具体 I/O 策略完全由宿主决定；实现不得返回共享且仍由其他对象拥有的图片。

## 说明

`Resolve` 会在 Engine 所属 UI 线程的同步场景构建中调用，因此实现必须非阻塞，
并应只返回已经预加载或缓存的图像。文件、网络和解码等异步工作必须由宿主提前完成；
解析器不应在此回调中等待 I/O。同一解析器实例可以安装到多个 Engine，而这些 Engine
可能由不同线程同时构建；共享实现必须保证线程安全，否则宿主应为每个 Engine 提供独立实例。

## 方法

### `Resolve(String)`

解析一个不含 `image://` 前缀的图片源。

| 参数 | 说明 |
| --- | --- |
| `source` | 符号声明携带的原始图片源载荷。 |

**返回：** 独占图片的成功结果或带稳定诊断的失败结果；不得返回 `null`。
