# ChartBuiltInSymbolKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Rendering.Symbols`　**Chart 版本**：`0.1.1.25`

## 概述

通用符号工厂支持的内置几何种类。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Arrow` | 顶点向上的箭头。 |
| `Circle` | 在目标边界中居中的最大圆。 |
| `Diamond` | 菱形。 |
| `Line` | 水平线段。 |
| `Pin` | 以名义边界中心为尖端锚点、主要向上延伸的水滴状定位标记。 |
| `Rect` | 填满目标边界的矩形。 |
| `RoundRect` | 填满目标边界的圆角矩形。 |
| `Square` | 在目标边界中居中的正方形。 |
| `Triangle` | 顶点向上的三角形。 |
