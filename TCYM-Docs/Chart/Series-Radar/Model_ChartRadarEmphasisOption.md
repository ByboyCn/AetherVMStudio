# ChartRadarEmphasisOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

Radar emphasis 状态的线、面、符号及标签差异。

## 属性

| 名称 | 说明 |
| --- | --- |
| `AreaStyle` | 获取或设置此状态的面积差异；空对象启用默认面积。 |
| `Focus` | 获取或设置 none、self 或 series 聚焦范围。 |
| `LineStyle` | 获取或设置此状态的轮廓线差异。 |

## 方法

### `Clone`

创建值与 presence 隔离的状态副本。
