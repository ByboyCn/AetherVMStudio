# ChartRadarModule

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series`　**Chart 版本**：`0.1.1.25`

## 概述

原子安装 Radar 数据、布局、视觉、验证和持久系列 View。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ModuleKey` | 获取稳定的 Radar 系列模块注册键。 |

## 方法

### `Register(TCYM.UI.Chart.Core.ChartRegistry)`

将 Radar 系列注册到已安装系列基础和 Radar 坐标模块的注册表。
