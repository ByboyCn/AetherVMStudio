# ChartTitleItemLayoutSnapshot

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.Title`　**Chart 版本**：`0.1.1.25`

## 概述

保存一个 Title 组件的不可变 box、文本和身份布局。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Bounds` | 获取共享标题边框盒。 |
| `BoxStyle` | 获取共享外框不可变样式。 |
| `ComponentId` | 获取 Title 显式 Id。 |
| `ComponentIndex` | 获取 Title 同类索引。 |
| `Subtext` | 获取非空副标题布局；副标题为空时为空。 |
| `Text` | 获取非空主标题布局；主标题为空时为空。 |
