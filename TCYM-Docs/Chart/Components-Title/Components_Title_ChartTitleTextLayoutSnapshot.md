# ChartTitleTextLayoutSnapshot

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Components.Title`　**Chart 版本**：`0.1.1.25`

## 概述

保存单个主标题或副标题的不可变排版、位置和交互投影。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Layout` | 获取渲染、测量和命中共享的公共文本布局。 |
| `Link` | 获取可选原始链接。 |
| `Role` | 获取主标题或副标题身份。 |
| `Target` | 获取链接目标；没有链接时仍保留有效默认值。 |
| `TriggerEvent` | 获取是否公开 title 组件 metadata。 |
| `X` | 获取文本元素局部原点 X。 |
| `Y` | 获取文本元素局部原点 Y。 |
