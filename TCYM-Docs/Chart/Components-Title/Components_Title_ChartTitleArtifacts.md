# ChartTitleArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Components.Title`　**Chart 版本**：`0.1.1.25`

## 概述

集中定义 Title Layout 阶段发布的全局强类型制品键。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Layout` | 获取当前候选或最后成功 Title 聚合布局。 |

## 字段

| 名称 | 说明 |
| --- | --- |
| `LayoutArtifactName` | Title 聚合布局的稳定制品名称。 |
