# ChartScaleTick

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Scales`　**Chart 版本**：`0.1.1.25`

## 概述

表示一个已经映射到输出坐标的比例尺刻度。

## 构造函数

### `ChartScaleTick(TCYM.UI.Chart.Data.ChartValue,Double)`

表示一个已经映射到输出坐标的比例尺刻度。

| 参数 | 说明 |
| --- | --- |
| `Value` | 刻度对应的原始图表值。 |
| `Coordinate` | 刻度在当前输出范围中的有限坐标。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Coordinate` | 刻度在当前输出范围中的有限坐标。 |
| `Value` | 刻度对应的原始图表值。 |
