# ChartTimeUnit

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Scales`　**Chart 版本**：`0.1.1.25`

## 概述

标识时间比例尺自动刻度使用的 UTC 日历单位。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Day` | UTC 日历日。 |
| `Hour` | 小时。 |
| `Millisecond` | 毫秒。 |
| `Minute` | 分钟。 |
| `Month` | UTC 日历月。 |
| `Second` | 秒。 |
| `Week` | 以星期一为起点的 UTC 日历周。 |
| `Year` | UTC 日历年。 |
