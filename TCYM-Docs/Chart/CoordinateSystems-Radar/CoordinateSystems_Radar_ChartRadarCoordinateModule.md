# ChartRadarCoordinateModule

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Radar`　**Chart 版本**：`0.1.1.25`

## 概述

原子装配独立 Radar option、坐标工厂、布局与组件视图。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ModuleKey` | 获取坐标模块的稳定键。 |

## 方法

### `Register(TCYM.UI.Chart.Core.ChartRegistry)`

原子注册完整坐标模块；重复模块或扩展键冲突会抛出异常且不留下部分注册。
