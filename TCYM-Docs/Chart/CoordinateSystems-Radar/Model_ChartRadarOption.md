# ChartRadarOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

独立雷达坐标组件。指标是独立数值轴，不依赖 radiusAxis 或 angleAxis；像素长度采用图表 DIP。

## 属性

| 名称 | 说明 |
| --- | --- |
| `AxisLabel` | 获取或设置各指标的数值刻度标签；空块重置，默认隐藏。 |
| `AxisLine` | 获取或设置指标轴线；空块重置。 |
| `AxisName` | 获取或设置指标名称样式、rich 和 formatter；空块重置，默认显示。 |
| `AxisNameGap` | 获取或设置指标名称距外圈的非负 DIP 间距；默认 15。 |
| `AxisTick` | 获取或设置指标刻度线；空块重置，默认隐藏。 |
| `Center` | 获取或设置中心；空值恢复 50%/50%。 |
| `Clockwise` | 获取或设置指标排列是否顺时针；空值恢复逆时针。 |
| `ComponentType` | 获取组件注册与合并所使用的类型名。 |
| `Indicator` | 获取或整体替换指标数组；空值/空数组清除全部指标，列表修改同样表示整体替换。 |
| `Radius` | 获取或设置内外半径；空值恢复零内半径和 50% 外半径。 |
| `Scale` | 获取或设置自动数值域是否不强制包含零；默认假。显式固定边界始终优先。 |
| `Shape` | 获取或设置网格形状；空值恢复多边形。 |
| `SplitArea` | 获取或设置交替环带；空块重置，默认显示。 |
| `SplitLine` | 获取或设置同心分隔线；空块重置，默认显示。 |
| `SplitNumber` | 获取或设置一至一千的固定分段数；空值恢复五段。 |
| `StartAngle` | 获取或设置首指标的有限角度；零度朝右，默认 90 度朝上。 |
| `TriggerEvent` | 获取或设置轴文本是否携带组件事件元数据。 |

## 方法

### `Clone`

创建复制公共选项数据的新节点。实现应调用相应 Copy*To helper；返回后合并引擎会重新规范化
canonical identity，因此自定义派生类型也不能意外复制另一个节点的持久 view 身份。
