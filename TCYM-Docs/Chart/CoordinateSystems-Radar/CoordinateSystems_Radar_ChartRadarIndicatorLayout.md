# ChartRadarIndicatorLayout

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Radar`　**Chart 版本**：`0.1.1.25`

## 概述

冻结一个指标的名称、角度、范围和固定分段比例尺。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Angle` | 获取从右侧逆时针起算的角度。 |
| `Index` | 获取指标索引。 |
| `Maximum` | 获取最终上界。 |
| `Minimum` | 获取最终下界。 |
| `Name` | 获取未格式化指标名称。 |
| `Scale` | 获取不变线性比例尺。 |
