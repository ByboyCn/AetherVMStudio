# ChartRadarIndicatorOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

声明一根雷达指标轴的名称、有限数值边界和名称颜色。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Color` | 获取或设置该指标名称的颜色；空值继承 axisName。 |
| `Max` | 获取或设置有限固定上界；空值根据可见数据自动计算。 |
| `Min` | 获取或设置有限固定下界；空值根据可见数据自动计算。 |
| `Name` | 获取或设置指标名称。 |

## 方法

### `Clone`

创建与来源独立的指标声明。
