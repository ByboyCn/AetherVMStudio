# ChartRadarValuesItem

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Radar`　**Chart 版本**：`0.1.1.25`

## 概述

保存一项多维原始值和稳定数据身份；构造时复制值序列。

## 构造函数

### `ChartRadarValuesItem(TCYM.UI.Chart.Data.ChartDataKey,Int32,Int32,String,Collections.Generic.IEnumerable{TCYM.UI.Chart.Data.ChartValue})`

创建独立的雷达向量。
