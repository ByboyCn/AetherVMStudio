# ChartRadarLayoutItem

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Radar`　**Chart 版本**：`0.1.1.25`

## 概述

一个 Radar 组件的权威布局及坐标快照。

## 属性

| 名称 | 说明 |
| --- | --- |
| `ComponentId` | 获取组件业务 ID。 |
| `ComponentIndex` | 获取同主类型组件索引。 |
| `CoordinateSystem` | 获取独立不可变坐标。 |
| `Indicators` | 获取独立指标轴列表。 |
