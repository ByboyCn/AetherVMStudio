# ChartAxisMinorSplitLineOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示连续轴次分隔线的显示和线条样式。

## 属性

| 名称 | 说明 |
| --- | --- |
| `LineStyle` | 获取或设置次分隔线样式；空或未修改实例表示整块重置。 |
| `Show` | 获取或设置是否显示次分隔线。 |

## 方法

### `Clone`

创建独立 minorSplitLine 副本。

**返回：** 独立副本。

### `Reset`

显式恢复整个 minorSplitLine 默认值。
