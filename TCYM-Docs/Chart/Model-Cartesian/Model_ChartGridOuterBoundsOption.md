# ChartGridOuterBoundsOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 ECharts 6 grid.outerBounds 的独立矩形约束补丁。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Bottom` | 获取或设置外边界底部约束。 |
| `Height` | 获取或设置外边界高度。 |
| `Left` | 获取或设置外边界左侧约束。 |
| `Right` | 获取或设置外边界右侧约束。 |
| `Top` | 获取或设置外边界顶部约束。 |
| `Width` | 获取或设置外边界宽度。 |

## 方法

### `Clone`

创建值与 presence 日志均隔离的 outerBounds 副本。

**返回：** 独立副本。

### `Reset`

显式把所有 outerBounds 字段恢复到 grid 默认值。
