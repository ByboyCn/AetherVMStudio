# ChartAxisLineOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示坐标轴主轴线的显示、零轴对齐、端点符号和线条样式。

## 属性

| 名称 | 说明 |
| --- | --- |
| `LineStyle` | 获取或设置轴线样式；赋空或赋入未修改实例会显式重置整块样式。 |
| `OnZero` | 获取或设置轴线是否与另一轴的零刻度对齐；空值表示自动。 |
| `OnZeroAxisIndex` | 获取或设置用于零轴对齐的另一坐标轴索引。 |
| `Show` | 获取或设置轴线是否显示；空值保留 ECharts 的自动解析语义。 |
| `Symbol` | 获取或设置标准物理轴线起点和终点的端点符号；空值使用无符号默认值。<br />X 轴标准方向为左至右，Y 轴为下至上；比例尺反向不会交换两个符号。 |
| `SymbolOffset` | 获取或设置物理起点和终点沿标准轴正方向的独立有限像素偏移。 |
| `SymbolSize` | 获取或设置两个端点符号共享的有限非负二维尺寸；空值使用默认尺寸。 |

## 方法

### `Clone`

创建独立 axisLine 副本。

**返回：** 独立副本。

### `Reset`

显式恢复整个 axisLine 默认值。
