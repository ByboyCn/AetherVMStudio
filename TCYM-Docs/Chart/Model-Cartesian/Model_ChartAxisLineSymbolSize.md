# ChartAxisLineSymbolSize

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示两个轴线端点符号共享的有限非负宽度和长度。

## 构造函数

### `ChartAxisLineSymbolSize(Single,Single)`

创建轴线端点符号的二维像素尺寸。

| 参数 | 说明 |
| --- | --- |
| `width` | 垂直于轴线方向的有限非负宽度。 |
| `height` | 沿符号指向方向的有限非负长度。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Height` | 获取沿符号指向方向的符号长度。 |
| `Width` | 获取垂直于轴线方向的符号宽度。 |
