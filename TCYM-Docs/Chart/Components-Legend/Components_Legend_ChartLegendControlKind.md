# ChartLegendControlKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Components.Legend`　**Chart 版本**：`0.1.1.25`

## 概述

标识 Legend 候选中的交互区域用途。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `InverseSelect` | 反选 selector。 |
| `Item` | 普通图例项。 |
| `PageInfo` | 滚动图例只读页码文字。 |
| `PageNext` | 滚动图例下一页按钮。 |
| `PagePrevious` | 滚动图例上一页按钮。 |
| `SelectAll` | 全选 selector。 |
