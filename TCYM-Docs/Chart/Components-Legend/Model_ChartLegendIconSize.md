# ChartLegendIconSize

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示可分别指定宽高的 Legend 图标尺寸。

## 构造函数

### `ChartLegendIconSize(Single,Single)`

创建有限非负图标尺寸。

| 参数 | 说明 |
| --- | --- |
| `width` | 图标宽度。 |
| `height` | 图标高度。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Height` | 获取图标高度。 |
| `Width` | 获取图标宽度。 |
