# ChartLegendPageIcons

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

保存 scroll Legend 水平和垂直方向的前后翻页图标声明。

## 属性

| 名称 | 说明 |
| --- | --- |
| `HorizontalNext` | 获取或设置水平方向下一页图标。 |
| `HorizontalPrevious` | 获取或设置水平方向上一页图标。 |
| `VerticalNext` | 获取或设置垂直方向下一页图标。 |
| `VerticalPrevious` | 获取或设置垂直方向上一页图标。 |

## 方法

### `Clone`

创建字符串值与 presence 日志独立的副本。

**返回：** 内容等价的新翻页图标容器。

### `Reset`

显式清除全部翻页图标声明。
