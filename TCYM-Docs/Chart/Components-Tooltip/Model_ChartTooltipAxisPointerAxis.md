# ChartTooltipAxisPointerAxis

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

标识 Tooltip 自动选择或显式指定的坐标轴维度。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Angle` | 极坐标角度轴。 |
| `Auto` | 由坐标系优先选择 category/time base axis。 |
| `Radius` | 极坐标半径轴。 |
| `X` | 直角坐标系 X 轴。 |
| `Y` | 直角坐标系 Y 轴。 |
