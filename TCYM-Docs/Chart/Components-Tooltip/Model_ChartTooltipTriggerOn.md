# ChartTooltipTriggerOn

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

标识允许触发 Tooltip 的原生指针事件组合。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Click` | 指针点击时触发。 |
| `MouseMove` | 指针移动时触发。 |
| `MouseWheel` | 滚轮可能改变 dataZoom 视图时重新触发。 |
| `None` | 不由指针事件触发，只接受手动 action 或 axisPointer handle。 |
