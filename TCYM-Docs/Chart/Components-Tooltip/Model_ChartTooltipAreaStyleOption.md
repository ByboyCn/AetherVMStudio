# ChartTooltipAreaStyleOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 axisPointer shadow 的 presence-aware 区域样式。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Color` | 获取或设置阴影区域画刷；显式空值恢复继承值。 |

## 方法

### `Clone`

创建隔离画刷与 presence 的副本。

**返回：** 等价新样式。

### `Reset`

显式清除整个区域样式块。
