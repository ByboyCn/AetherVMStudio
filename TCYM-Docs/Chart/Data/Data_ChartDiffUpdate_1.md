# ChartDiffUpdate&lt;T1&gt;

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Data`　**Chart 版本**：`0.1.1.25`

## 概述

描述一对稳定键相同的前后数据项。

## 构造函数

### `ChartDiffUpdate<T1>(Int32,Int32,,)`

描述一对稳定键相同的前后数据项。

| 参数 | 说明 |
| --- | --- |
| `OldIndex` | 旧数据中的索引。 |
| `NewIndex` | 新数据中的索引。 |
| `Previous` | 旧项。 |
| `Current` | 新项。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `Current` | 新项。 |
| `NewIndex` | 新数据中的索引。 |
| `OldIndex` | 旧数据中的索引。 |
| `Previous` | 旧项。 |
