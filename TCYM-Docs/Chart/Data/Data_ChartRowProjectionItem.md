# ChartRowProjectionItem

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Data`　**Chart 版本**：`0.1.1.25`

## 概述

附加到 `SeriesLayoutByRow` 所生成数据项的元数据；
该项的值由指定物理列跨所有物理行读取而成。

## 构造函数

### `ChartRowProjectionItem(Int32,TCYM.UI.Chart.Data.ChartDimension)`

附加到 `SeriesLayoutByRow` 所生成数据项的元数据；
该项的值由指定物理列跨所有物理行读取而成。

| 参数 | 说明 |
| --- | --- |
| `SourceColumnIndex` | 物理来源列索引。 |
| `SourceDimension` | 物理来源列的维度定义。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `SourceColumnIndex` | 物理来源列索引。 |
| `SourceDimension` | 物理来源列的维度定义。 |
