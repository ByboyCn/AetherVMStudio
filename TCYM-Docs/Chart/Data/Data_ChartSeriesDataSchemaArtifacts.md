# ChartSeriesDataSchemaArtifacts

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Data`　**Chart 版本**：`0.1.1.25`

## 概述

集中定义每系列公共数据 schema 的稳定制品键。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ArtifactName` | 获取 schema 的稳定制品名称。 |

## 方法

### `ForSeries(TCYM.UI.Chart.Model.ChartSeriesOption)`

按系列规范身份创建 schema 制品键。

| 参数 | 说明 |
| --- | --- |
| `series` | 当前有效系列。 |

**返回：** 稳定的每系列键。
