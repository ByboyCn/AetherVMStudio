# ChartPolarComponentViewFactory

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.CoordinateSystems.Polar`　**Chart 版本**：`0.1.1.25`

## 概述

为每个 polar 组件实例创建独立的持久视图。

## 属性

| 名称 | 说明 |
| --- | --- |
| `ComponentType` | 获取工厂支持的组件主类型。 |

## 方法

### `CreateView`

创建尚未附加到引擎场景的 polar 持久视图。

**返回：** 全新的 polar 组件视图。
