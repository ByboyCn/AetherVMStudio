# ChartPieLabelPosition

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

指定 Pie 标签相对于扇区的位置。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Center` | 位于圆心。 |
| `Inner` | `Inside` 的 ECharts 兼容别名 `inner`。 |
| `Inside` | 位于扇区内部，对应 `inside`。 |
| `Outer` | 位于扇区外侧，对应 `outer`。 |
| `Outside` | `Outer` 的 ECharts 兼容别名 `outside`。 |
