# ChartPieLabelRotationKind

> **类型**：enum　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

指定 Pie 标签旋转联合值的类别。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `Degrees` | 使用明确的顺时针角度；零度也对应布尔 `false`。 |
| `Radial` | 沿径向旋转；也对应布尔 `true`。 |
| `Tangential` | 沿扇区切线旋转并自动翻转保持可读。 |
| `TangentialNoFlip` | 沿扇区切线旋转但不自动翻转。 |
