# ChartTooltipAxisQueryMatch

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Visual`　**Chart 版本**：`0.1.1.25`

## 概述

保存 axis nearest 查询中的单个稳定匹配项。

## 属性

| 名称 | 说明 |
| --- | --- |
| `DataPoint` | 获取命中的轴数据点；默认结构为 null。 |
| `Descriptor` | 获取命中的 descriptor；默认结构为 null。 |
| `StableOrder` | 获取 descriptor 稳定顺序；默认结构为 -1。 |
