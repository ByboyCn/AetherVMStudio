# ChartTreeLeavesOption

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

Tree 叶子与折叠分支节点的正常和状态样式补丁。

## 属性

| 名称 | 说明 |
| --- | --- |
| `Blur` | 叶子淡化状态。 |
| `Emphasis` | 叶子强调状态。 |
| `ItemStyle` | 叶子正常样式。 |
| `Label` | 叶子标签；在系列标签之上合并。 |
| `LineStyle` | 叶子节点入边的正常样式。 |
| `Select` | 叶子选择状态。 |

## 方法

### `Clone`

创建样式及 presence 独立的副本。
