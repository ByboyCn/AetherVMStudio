# ChartTreeModule

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Series`　**Chart 版本**：`0.1.1.25`

## 概述

注册原生树图的数据、布局、视觉、交互和持久场景管线。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ModuleKey` | Tree 模块的稳定注册键。 |

## 方法

### `Register(TCYM.UI.Chart.Core.ChartRegistry)`

原子注册 Tree；要求 SeriesFoundation 已安装。

| 参数 | 说明 |
| --- | --- |
| `registry` | 目标注册表。 |

**返回：** 目标注册表。
