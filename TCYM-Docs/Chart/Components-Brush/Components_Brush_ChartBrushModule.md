# ChartBrushModule

> **类型**：static class　**命名空间**：`TCYM.UI.Chart.Components.Brush`　**Chart 版本**：`0.1.1.25`

## 概述

原子装配 Brush 的状态、选择、视觉、cover 与交互运行时。

## 字段

| 名称 | 说明 |
| --- | --- |
| `ModuleKey` | 获取 Brush 组件的稳定模块键。 |

## 方法

### `Register(TCYM.UI.Chart.Core.ChartRegistry)`

把 Brush 运行时原子注册到指定 Registry。

| 参数 | 说明 |
| --- | --- |
| `registry` | 接收 Brush 注册项的 Registry。 |

**返回：** 传入 Registry。
