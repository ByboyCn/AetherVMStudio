# ChartBrushCoordinatePoint

> **类型**：struct　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

表示 Polygon Brush 的一个强类型 Cartesian 坐标点。

## 构造函数

### `ChartBrushCoordinatePoint(TCYM.UI.Chart.Data.ChartValue,TCYM.UI.Chart.Data.ChartValue)`

创建坐标点并立即隔离两个 ChartValue 载荷。

| 参数 | 说明 |
| --- | --- |
| `x` | X 坐标值。 |
| `y` | Y 坐标值。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `X` | 获取 X 坐标值。 |
| `Y` | 获取 Y 坐标值。 |
