# ChartBrushLineXArea

> **类型**：sealed class　**命名空间**：`TCYM.UI.Chart.Model`　**Chart 版本**：`0.1.1.25`

## 概述

定义只约束 X 坐标闭区间的 Brush area。

## 构造函数

### `ChartBrushLineXArea(TCYM.UI.Chart.Model.ChartBrushValueRange)`

创建 X 轴线性区域。

| 参数 | 说明 |
| --- | --- |
| `range` | X 坐标闭区间。 |

## 属性

| 名称 | 说明 |
| --- | --- |
| `BrushType` | 获取当前区域的几何类型。 |
| `Range` | 获取 X 坐标闭区间。 |

## 方法

### `Clone`

创建几何、共同字段、画刷和 presence 均隔离的同类型副本。
