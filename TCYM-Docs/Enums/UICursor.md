# UICursor

> **类型**：枚举　**分类**：Enums　**框架版本**：`0.1.1.24`

## 概述

鼠标指针类型枚举，对标常见 CSS cursor 值。

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `Default` | - | 默认指针（CSS: default）。 |
| `Help` | - | 帮助指针，通常显示问号（CSS: help）。 |
| `Pointer` | - | 手型指针，表示可点击（CSS: pointer）。 |
| `Progress` | - | 进度指针，表示正在进行但可交互（CSS: progress）。 |
| `Wait` | - | 等待指针，表示不可交互的忙碌状态（CSS: wait）。 |
| `Crosshair` | - | 十字光标，常用于精确选择（CSS: crosshair）。 |
| `Cell` | - | 表格单元选择指针（CSS: cell）。 |
| `Text` | - | 文本选择光标（I-beam）（CSS: text）。 |
| `Alias` | - | 创建别名的指针（CSS: alias）。 |
| `Copy` | - | 复制操作指针（CSS: copy）。 |
| `Move` | - | 移动操作指针（CSS: move）。 |
| `NotAllowed` | - | 禁止/不允许的指针（CSS: not-allowed）。 |
| `Grab` | - | 抓取手型，表示可拖拽（CSS: grab）。 |
| `Grabbing` | - | 抓取中手型，表示正在拖拽（CSS: grabbing）。 |
| `ColResize` | - | 列宽调整指针（CSS: col-resize）。 |
| `RowResize` | - | 行高调整指针（CSS: row-resize）。 |
| `Resize` | - | 通用调整大小指针（CSS: resize，非标准，通常使用各方向的调整指针）。 |
| `NeResize` | - | 右上角方向调整大小指针，等同于 ne-resize（CSS: ne-resize）。 |
| `ZoomIn` | - | 放大指针（CSS: zoom-in）。 |
| `ZoomOut` | - | 缩小指针（CSS: zoom-out）。 |
| `NwseResize` | - | 左上/右下方向调整大小（CSS: nwse-resize）。追加成员不改变已有枚举数值。 |
| `VerticalText` | - | 垂直文本选择（CSS: vertical-text）。 |
| `ContextMenu` | - | 上下文菜单（CSS: context-menu）。 |
| `None` | - | 隐藏客户区光标（CSS: none）。 |
