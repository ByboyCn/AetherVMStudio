# UIWindowShadowPreference

> **类型**：枚举　**分类**：Enums　**框架版本**：`0.1.1.24`

## 概述

指定原生窗口外阴影偏好。

## 说明

Windows 10 通过主 HWND 的 DWM 策略请求阴影，不创建辅助窗口。 阴影可见性受系统视觉效果、合成器与 Region 限制。Windows 11、macOS 与 Linux 的系统阴影由窗口管理器控制，框架会保存偏好但不覆盖平台行为。

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `Default` | 0 | Windows 10 的显式圆角窗口自动请求系统阴影，其它情况由平台决定。 |
| `Enabled` | 1 | 在支持的平台上显式启用窗口外阴影。 |
| `Disabled` | 2 | 在支持的平台上显式禁用窗口外阴影。 |
