# FilePickerOpenOptions

> **类型**：类　**分类**：Storage　**框架版本**：`0.1.1.24`

## 概述

文件选择参数

## 属性

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `Title` | `string?` | 对话框标题。 |
| `AllowMultiple` | `bool` | 是否允许多选。 |
| `SuggestedStartLocation` | `string?` | 建议的起始路径。可传目录，也可传现有文件路径。 |
| `FileTypeFilter` | `IReadOnlyList<FilePickerFileType>?` | 文件类型过滤列表。 |
