# FolderPickerOpenOptions

> **类型**：类　**分类**：Storage　**框架版本**：`0.1.1.24`

## 概述

文件夹选择参数，接口形态参考 Avalonia 的 FolderPickerOpenOptions。

## 属性

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `Title` | `string?` | 对话框标题。 |
| `AllowMultiple` | `bool` | 是否允许多选。 |
| `SuggestedStartLocation` | `string?` | 建议的起始目录。 |
