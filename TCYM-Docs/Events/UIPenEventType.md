# UIPenEventType

> **类型**：枚举　**分类**：Events　**框架版本**：`0.1.1.24`

## 概述

笔（触控笔 / 数位笔）事件类型。 该事件来自 SDL3 新增的 pen 子系统，SDL2 时代没有独立的笔事件（只能混在鼠标 / 触摸里）。

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `ProximityIn` | - | 笔进入感应范围（悬停在屏幕上方但未接触）。 |
| `ProximityOut` | - | 笔离开感应范围。 |
| `Down` | - | 笔尖接触屏幕（落笔）。 |
| `Up` | - | 笔尖离开屏幕（抬笔）。 |
| `Move` | - | 笔移动（悬停或接触时）。 |
| `ButtonDown` | - | 笔身按钮按下。 |
| `ButtonUp` | - | 笔身按钮抬起。 |
