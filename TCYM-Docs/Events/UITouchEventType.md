# UITouchEventType

> **类型**：枚举　**分类**：Events　**框架版本**：`0.1.1.24`

## 概述

触摸事件类型

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `TouchStart` | - | 触摸开始事件，表示一个或多个触摸点开始接触屏幕。 |
| `TouchMove` | - | 触摸移动事件，表示一个或多个触摸点在屏幕上移动。 |
| `TouchEnd` | - | 触摸结束事件，表示一个或多个触摸点离开屏幕。 |
| `TouchCancel` | - | 触摸取消事件，表示系统取消了一个或多个触摸点的跟踪（例如由于来电、系统警告等中断）。被取消的触摸点将不再触发 TouchMove 或 TouchEnd 事件。 |
