# UIKeyModifiers

> **类型**：枚举　**分类**：Events　**框架版本**：`0.1.1.24`

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `None` | 0 | 无修饰键 |
| `Shift` | 1 << 0 | Shift 键 |
| `Ctrl` | 1 << 1 | Ctrl 键 |
| `Alt` | 1 << 2 | Alt 键 |
| `Super` | 1 << 3 | Windows键 或 Command键 |
| `Caps` | 1 << 4 | Caps Lock 键 |
| `Num` | 1 << 5 | Num Lock 键 |
