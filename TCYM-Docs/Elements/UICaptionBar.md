# UICaptionBar

> **类型**：类　**分类**：Elements　**框架版本**：`0.1.1.24`

**继承 / 实现**：`UIView`

## 概述

自定义标题栏组件（支持图标、标题、最小化/最大化/关闭按钮）。

## 属性

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `CaptionBoxStyle` | `UIStyle` | 标题栏框样式（支持 DefaultUIStyle / UpdateUIStyle）。 |
| `IconPath` | `string` | ICO 图标路径。 |
| `IsShowIcon` | `bool` | 是否显示 ICO 图标。 |
| `CaptionTitle` | `string` | 标题文本。 |
| `CaptionTitleStyle` | `UIStyle` | 标题文本样式（支持 DefaultUIStyle / UpdateUIStyle）。 |
| `IsShowMin` | `bool` | 是否显示最小化按钮。 |
| `MinStyle` | `DefaultUIStyle` | 最小化按钮样式。 |
| `IsShowMax` | `bool` | 是否显示最大化按钮。 |
| `MaxStyle` | `DefaultUIStyle` | 最大化按钮样式。 |
| `CloseStyle` | `DefaultUIStyle` | 关闭按钮样式。 |
