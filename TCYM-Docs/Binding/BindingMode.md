# BindingMode

> **类型**：枚举　**分类**：Binding　**框架版本**：`0.1.1.24`

## 概述

绑定模式枚举，描述绑定的方向和时机。

## 枚举值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| `Default` | -1 | 使用目标属性声明的默认绑定模式。 |
| `OneTime` | 0 | 一次绑定：在绑定建立时从源同步一次数据，之后不再更新。 |
| `OneWay` | 1 | 单向绑定：源属性变化时更新目标属性（源 -> 目标）。 |
| `TwoWay` | 2 | 双向绑定：源与目标互相同步，当目标变化时也会更新源（源 - 目标）。 |
| `OneWayToSource` | 3 | 单向回写：仅把目标属性变化同步到源属性。 |
